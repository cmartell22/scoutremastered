# Changelog

All notable changes to Scout Remastered are documented here.

## 1.0.0-rc.1 - 2026-08-12

- First release candidate for Minecraft 26.1.2 on Fabric.
- Added wearable satchels and left/right belt pouches with contents owned by each physical ItemStack.
- Added the server-authoritative B-key Pack Inventory, deterministic shift-click routing, immediate persistence, and nested-bag rejection.
- Added Trinkets Updated equipment discovery, tooltips, third-person placeholder rendering, and component-preserving upgrade recipes.
- Added an opt-in Integrated Inventory prototype. It is disabled by default and preserves the independent B-key Pack Inventory.
